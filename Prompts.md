# Prompts Used

## Prompt 1 — Project Initialization

Asked for guidance on initializing the Node.js + Express Data Hub project.

## Prompt 2 — REST API Scaffolding

Asked for help creating the required Blog REST endpoints.

## Prompt 3 — CRUD Implementation

Asked for guidance implementing CRUD operations and testing them with Thunder Client.

## Prompt 4 — Middleware

Asked for guidance creating custom request logging middleware.

## Prompt 5 — Authentication

Asked for guidance implementing the mock POST /login endpoint.

## Prompt 6 — MongoDB Atlas Setup

Asked for guidance connecting the Data Hub API to MongoDB Atlas using Mongoose and environment variables.

## Prompt 7 — Mongoose Models

Asked for help creating the Post and User schemas with the required fields and relationships.

## Prompt 8 — MongoDB CRUD Migration

Asked for guidance replacing the in-memory blogPosts array with MongoDB operations using Mongoose.

## Prompt 9 — Referencing and Populate

Asked for guidance connecting posts to users using authorId and Mongoose populate.

## Prompt 10 — Recent Posts

Asked for guidance creating a route that returns the three most recent posts using sorting and limiting.

## Prompt 11 — API Testing

Asked for help testing the MongoDB-backed CRUD operations, user creation, populated posts, and recent posts route using Thunder Client.

## Prompt 12 — Deployment Preparation

Asked for guidance preparing the MongoDB-backed API for deployment and keeping the MongoDB connection string secure.
